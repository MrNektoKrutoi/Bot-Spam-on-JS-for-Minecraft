# Minecraft Бот-Спамер

Node.js бот для Minecraft серверов, который позволяет создавать несколько ботов для одновременного подключения к серверу и спама сообщениями в чат.

## Возможности

- Подключение нескольких ботов к любому Minecraft серверу
- Настраиваемые имена ботов (статические или случайные)
- Спам сообщениями (свои сообщения, случайные или без сообщений)
- Настраиваемая задержка между сообщениями
- Режим безлимитных ботов (`/nolimit`)
- Автоматическая обработка повторяющихся имён

## Установка

### Если у вас установлен Node.js:

1. Скачайте файл `bot.js`
2. Откройте терминал/командную строку в папке с файлом
3. Установите зависимость:
```bash
npm install mineflayer
```

### Если у вас НЕ установлен Node.js:

1. Перейдите на официальный сайт: https://nodejs.org/
2. Скачайте и установите **LTS версию** Node.js
3. После установки Node.js, npm установится автоматически
4. Выполните шаги из раздела "Если у вас установлен Node.js"

## Использование

Запустите скрипт:

```bash
node bot.js
```

После запуска следуйте инструкциям в консоли.

Этот инструмент предназначен только для образовательных целей. Используйте его только на серверах, где у вас есть разрешение на запуск ботов. Автор не несёт ответственности за неправомерное использование или нарушение правил серверов.
